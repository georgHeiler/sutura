# Security

Use the security-audit skill for source-first codebase reviews, focused vulnerability research,
and security questions. It requires a concrete trust-boundary failure before calling a candidate a
finding, and keeps deployment-dependent claims in `needs_validation`.

| Skill | Entry point | When to open |
| --- | --- | --- |
| `security-audit` | `security-audit/SKILL.md` | A security audit, vulnerability review, or security question. |
